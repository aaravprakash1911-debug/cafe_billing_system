# Project Statement

## Problem Statement

restaurants, food stalls, cafés often need a fast and easy method to record a customer’s order and compute the final bill without using costly point‑of‑sale software. Adding prices by hand is slow. Can cause mistakes especially when a customer orders many items. This project solves that issue by giving a terminal‑based ordering system that lets a user pick menu items and automatically adds up the right total.

## Scope of the Project

This project is a beginner, console‑based program that shows programming ideas instead of being a full production system. The scope covers:

- A set menu that lists item names and prices.

- The user can order one item. Then add more items if they wish.

- Simple check to see if the ordered item is on the menu.

- Automatic update of the running total of the order.

- Show a bill summary when the session ends.

**Out of scope** (not covered by this version of the project):

- A graphical user interface or web interface.

- Persistent storage of orders (e.g. Saving orders to a file or database).

- Handling item quantities (e.g. Ordering 2 pizzas at once).

- Payment processing or integration with point‑of‑sale/payment systems.

- Multi‑user or multi‑table order management.

## Target Users

-. Beginners learning Python who want a simple real‑world project to practice dictionaries, loops and conditionals.

- Small restaurant or café owners who want a very basic no‑cost way to add up a customer’s order using a terminal.

- Instructors or educators who might use this as an example project to teach basic programming concepts.

## High‑Level Features

- Show all menu items and their prices.

- Order entry. The user can type the name of the item they want.

- Menu validation. Check if the entered item is available.

- ordering. The user can add many items, in one session using a loop.

- Running total calculation. The bill amount updates automatically as items are added.

- Final bill summary and a closing thank‑you message.
